# Zonix-Analytics
Zonix es un sistema inteligente de analítica de tráfico peatonal y mapas de calor por pasillos diseñado para tiendas físicas y mercados locales. Permite optimizar la distribución de productos, identificar zonas de alta y baja retención de clientes, y maximizar las ventas de los pequeños comercios de forma automatizada y sin vulnerar la privacidad.
