# ZONIX - RetailVision Analytics

## Breve Descripcion del Proyecto
ZONIX es un sistema de vision por computador anonima y analitica espacial para tiendas fisicas y pequeños comercios. Analiza el flujo de movimiento por cuadrantes o pasillos en memoria volatil (sin almacenar imagenes ni identificar rostros), genera un mapa de calor visual, guarda el historial en una base de datos SQLite y ofrece recomendaciones para mejorar la distribucion de productos y las ventas.
